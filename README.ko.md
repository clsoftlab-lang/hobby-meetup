# 같이해요 — 취미 기반 모임 & 친구 매칭

혼자보다 함께가 즐거운 **공개·소규모 취미 모임** 앱입니다. 등산·보드게임·러닝·전시관람·
스터디·사진출사·요리클래스·자전거·클라이밍을 좋아하는 사람들을 연결해요. 공유하는 취미를
통한 건전한 만남이 목표입니다.

> 🌿 **의도적인 건전화(리프레이밍).** 이 프로젝트는 사회적으로 문제가 있는 "유료 데이트"
> C2C 마켓플레이스 아이디어를 **안전하고 긍정적인 취미 기반 그룹 모임 앱**으로 의도적으로
> 바꿔 만든 것입니다. **유료 데이트 없음, 연애/거래성 매칭 없음, 1:1 유료 만남 없음** —
> 오직 공유 취미를 중심으로 한 공개·소규모 활동만 다룹니다.

## ⚠️ 데모 모드 경계 (먼저 읽어주세요)

**모든 것이 브라우저 안에서만 동작합니다. 실제 서비스가 아닌 데모입니다.**

- **모든 모임과 호스트는 가상 데이터**입니다 (`data/*.json`).
- **localStorage를 사용하며 이것은 실제 데이터베이스가 아닙니다** — 참가·생성·후기·설문은
  내 기기에만 저장되고 아무와도 공유되지 않습니다.
- **실제 계정·개인정보(PII)·실제 신원인증이 없습니다.** 본인확인 배지, 매너온도, 신고
  기능은 모두 **목업(mock)**입니다.
- 실제 서비스라면: 백엔드 + 실제 DB, 실제 신원 인증, 사람에 의한 안전 심사, 인증/인가,
  악용 방지가 추가되어야 합니다.

## 기능 (데모에서 실제로 동작)

- **모임 탐색** — 취미 카테고리·지역·난이도 필터, 검색, 정렬(날짜/잔여석/호스트 평점).
- **모임 상세** — 활동 소개, 일정·공개 장소, 정원·현재 인원, 호스트 프로필(평점·매너온도),
  참가 신청.
- **참가 신청** — 신청하면 잔여 정원이 **즉시 감소**, 취소하면 자리 복구. 첫 신청 시
  **첫 참가자 환영 배지** 획득.
- **모임 만들기** — 폼 입력 → localStorage 저장.
- **취향 매칭** — 관심 취미·활동 성향·모임 규모·지역·난이도 설문 → **규칙 기반 추천 + 이유
  표시** ([`js/matcher.js`](js/matcher.js)).
- **내 모임** — 신청/주최한 모임, 내가 쓴 후기.
- **후기/평점** — 모임 날짜가 지난 뒤 별점 + 후기 작성.
- **안전장치** — 안전 가이드, 신고(mock), 매너온도/본인확인 배지(mock), 노쇼 방지 안내,
  소규모 정원 팁.
- **관심사 태그, 라이트/다크 테마, 반응형 모바일 우선 UI.**

## 매칭 방식 (`matcher.js`, 규칙 기반)

각 모임을 설문과 비교해 점수화하고 상위 8개(점수>0)를 **매칭 이유와 함께** 보여줍니다.

| 신호 | 점수 |
| --- | --- |
| 모임 카테고리가 내 관심사와 일치 | +40 |
| 카테고리 에너지가 내 활동성향과 일치(인접 +7) | +15 |
| 선호 지역에서 열림 | +20 |
| 난이도 일치 | +15 |
| 모임 규모 선호와 일치 | +15 |
| 호스트 신뢰 신호(본인확인/매너/평점) | 최대 +10 |

정렬은 점수 내림차순, **모집 중 → 마감** 순, 그다음 날짜순. 매치 퍼센트 = 점수/최대점수.
점수 함수는 순수 함수이며 `check.mjs`에서 단위 테스트합니다.

## 로컬 실행

빌드/의존성 없음. ES 모듈과 `fetch` 때문에 HTTP로 서빙해야 합니다.

```bash
python -m http.server 8996
# http://localhost:8996 접속
```

CI 검사:

```bash
node check.mjs
```

## 배포 (GitHub Pages)

루트에 `index.html`, 상대경로만 사용하는 정적 사이트입니다. **Settings → Pages → Deploy
from branch → `main` / root**로 활성화하면
`https://clsoftlab-lang.github.io/hobby-meetup/`에서 열립니다.

## 기술

프레임워크·번들러·런타임 의존성 없는 순수 **HTML + CSS + ES 모듈 JS**. 정적 JSON을
`fetch`로 로드, `localStorage`로 저장, 아바타/아트는 인라인 SVG.
